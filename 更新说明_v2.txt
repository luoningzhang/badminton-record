羽球手账 v2.0

1. 手机选择器全部重做：不再使用 datalist。
2. 邱德拔体育馆预置 12 个场地；五四体育馆预置 10 个场地。
3. 可添加/修改自定义场馆，并设置场地数量。
4. 球搭子可添加、多选、修改名称；旧名称自动保留为曾用名。
5. 球搭子档案增加球风、喜好、擅长、配合提示、备注和成长轨迹。
6. 历史记录使用 ID 关联，改名不会破坏过去统计。
7. 旧版数据自动迁移。
8. UI 全面移动端化，历史记录改成卡片样式，弹层适配 Android WebView。
9. 最低兼容 Android 8。
10. GitHub Actions 工作流已更新，避免旧 setup-android / Node 20 警告和 SDK tools 失败问题。

v2.1：移除场馆归档功能；删除首页说明句；旧数据中的 qdb/QDB 自动并入邱德拔体育馆。

v2.2：
1. 球搭子增加性别字段（女 / 男）。
2. 一场记录只保留一个场馆，场地改为按每个整点小时分别选择。
3. 支持“全部同第一小时”快速填充场地。
4. 历史单场地记录自动迁移；场地统计按实际小时计算。

v2.3：
1. 球搭子选择默认从最常打到最少打排序。
2. 球搭子档案新增性别、共同记录筛选。
3. 新增最常打、最近一起打、累计时长、姓名排序。
4. 档案卡增加最近一起打日期。

v2.4：
1. 球搭子新增详情统计。
2. 显示共同场次、累计共同小时和最近一起打日期。
3. 显示常去场馆排行。
4. 显示最近 5 条成长记录。
